外观

自定义 Nova Browser 的外观与主题
主题
选择浅色或深色界面风格
标签页位置
切换标签栏的显示位置（顶部横向 / 左侧纵向）
默认搜索引擎
在地址栏输入搜索词时使用的引擎
添加自定义搜索引擎
输入名称和搜索 URL 模板（用 %s 代替关键词，例如 https://yandex.com/search/?text=%s）
翻译提供商
在网页上使用翻译功能时的服务商
翻译目标语言
将外文网页翻译成哪种语言
使用说明
在任意网页点击地址栏旁的翻译按钮，即可将当前页面翻译为目标语言。
启动时打开
每次打开 Nova Browser 时显示的页面
主页地址
点击工具栏主页按钮时打开的网址；留空为新标签页
起始页 URL
自定义新标签页打开时自动加载的网址；留空则使用 Nova 默认起始页
下载位置
自动保存文件时的默认目录（留空则使用系统下载文件夹）
自动保存下载
开启后跳过保存对话框，直接下载到指定目录
显示下载通知
下载时在右下角显示进度提示
清除浏览数据
清除缓存、Cookie、历史记录和本地存储
拼写检查
在输入框中自动检查拼写错误
扩展安装
访问 Chrome 或 Edge 扩展商店下载扩展，或拖拽 .crx 文件到本窗口安装
已安装扩展
点击右侧可启用、禁用或移除扩展
提示：将下载好的 .crx 扩展文件拖到 Nova Browser 任意位置即可开始安装。
全部收藏 0
管理所有已收藏的网页，可跳转、重命名或删除
